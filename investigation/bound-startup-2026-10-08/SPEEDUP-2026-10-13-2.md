# Ускорение восстановления, второй проход — 13 октября 2026 (1.19.38)

После 1.19.37 (9 нативных APK, RRO настроек 1559 записей) обычная загрузка заняла **7,0 с** (старт 17,5 → конец 24,5 с работы системы). В `apply.sh` добавлены метки времени по этапам (`t_native_N`, `t_post_*`, `t_orig_*`, `t_ovload`, `t_pkgs`, `t_enabled`, `t_ov_loop`), по ним найдены основные потери.

## Что тормозило

| Этап | Время | Причина |
|---|---|---|
| Нативные APK | 3,3 с | `am force-stop` по одному и для каждого из 9 приложений (каждый вызов — запуск JVM, ~0,3 с), даже для незапущенных |
| Оверлеи (цикл) | 1,34 с | ~8 подоболочек `$(…)` на оверлей (`sig`, `cache_get`, `idmap_of`): ~15 оверлеев × ~90 мс |
| `cmd package list` | 0,35 с | JVM ради поиска путей `base.apk` оверлеев |
| Метки времени и проверки | ~0,4 с | `$(up)` и `$(stat …)`: по форку на каждое обращение |

## Что изменено (`generate_restore.py`)

1. **Перезапуск только запущенных приложений и параллельно.** Один снимок `ps -A -o NAME`; `am force-stop` запускается фоном только для приложений с процессом (`имя` или `имя:…`), затем один `wait`. SystemUI по-прежнему `kill -9`.
2. **Функции без форков** (`sigv`, `nsigv`, `check_hash2`, `rt_hash`, `up`): результат в переменной (`REPLY`, `RH`, `UPN`), uptime читается `$(</proc/uptime)`. Цикл по оверлеям считает ключи, пути idmap и подписи без подоболочек.
3. **Inode наших файлов** берётся из пакетной таблицы подписей, проверка монтирования в zygote — одним `nsenter stat` для всех девяти целей вместо девяти.
4. **Пути оверлеев** хранятся в `/data/local/beam-russifier-boot/ovpaths` (root 0600): путь меняется только при переустановке RRO. Если кэш не сходится по наличию файла или хешу — поиск шаблоном `/data/app/*/com.beam.translation.*/`, и лишь затем `cmd package list`. В журнал пишется `ov_source=cache|glob|pm`.
5. Исправлено сравнение имён в `case`: `"$NLpkg"` читалось как переменная `$NLpkg`; теперь `"${NL}pkg${NL}"` (раньше работало случайно из-за суффикса).

Контроль безопасности не ослаблен: те же хеши, те же проверки inode в процессах и в zygote, каждый оверлей по-прежнему проверяется по SHA256 манифеста (кэш путей лишь указывает, где файл).
