# Windows-интерфейс русификатора

Program.cs — WinForms-приложение без внешних библиотек. Компилируется системным csc для .NET Framework 4.8; на целевом ПК не нужен SDK. Python и ADB берутся из kit, собранного из проверенного неизменного ZIP русификатора. Launcher исходники не изменяются.

Сначала создайте проверенный ZIP текущего русификатора: `python russifier/build_release.py --boot-bundle investigation/bound-startup-2026-10-08`. Затем `python installer-ui/build.py`. Версия перевода читается из manifest.json; текущий результат — dist/XGIMI-Russifier-1.19.39-Windows-Setup1.16, отдельный ZIP и SHA256. Существующая папка выпуска не перезаписывается. Все исполняемые файлы kit берутся из проверенного ZIP, без подмешивания другой версии скриптов. package.json содержит хеши входящих файлов.

## Окно установщика (1.16)

Три шага на одном экране: **1. Подключение** (IP проектора, запоминается; подсказка «Как включить ADB»), **2. Что сделать**, ход выполнения и итог.

Пять задач: «Проверить проектор» (только чтение), «Установить русификацию» (язык, базы, перевод, автозапуск; на странице сразу отмечаются все параметры первой настройки: часовой пояс, отключение фоновых китайских сервисов, лаунчер BEAM (клавиатура LeanKey скачивается вместе с ним) и модуль кнопок пульта — после перевода модуль ставится тем же запуском), «Обновить русификацию», «Удалить русификацию» и «Дополнительно» (кнопки пульта: установить/обновить, включить, отключить, восстановить после сбоя; подготовка языка, пояса и сервисов отдельно от установки, показать состояние, отменить подготовку; лаунчер BEAM и возврат отключённых лаунчеров; восстановление после прерванной установки).

Для операций, которым нужна резервная копия (удаление, восстановление, отмена подготовки), установщик сам берёт самую свежую подходящую папку из kit/runs и показывает её дату; «Другая…» позволяет выбрать вручную. Если «Установить» запущено на проекторе с уже установленным русификатором, предлагается обновление. Режим «обычная установка без автозапуска» в окне больше не показывается: без helper перевод пропадает после перезагрузки; команды `install`/`rollback` остаются в launch.py для ручного режима.

Итог операции выводится крупным цветным сообщением (зелёное — готово и что делать дальше, жёлтое — нужна перезагрузка и повтор, красное — причина ошибки); полный вывод — под ссылкой «Подробности».

Отдельные действия позволяют установить/обновить, включить, отключить и восстановить активацию независимого модуля кнопок. APK включён в ZIP; его SHA256 проверяется при сборке и перед установкой. Подробности — [REMOTE-BUTTONS.md](../russifier/REMOTE-BUTTONS.md).

GUI запускает только известные команды launch.py, без shell. Аргументы экранируются по правилам Windows, адрес проверяется. На время операции поля заблокированы, закрытие окна запрещено, процесс не убивается. Успех показывается только при exit code 0; код 10 означает подготовленный язык с требованием reboot. Другие устройства автоматически не выбираются. Подготовка и необязательная установка BEAM описаны в PREPARATION.md. Настройки BEAM применяются только при явном выборе установки BEAM.

Для локальной проверки без ADB: `XgimiInstaller.exe --self-test` проверяет адрес/экранирование, создаёт окно, сохраняет ui-smoke.png и завершает процесс. Это проверка запуска и компоновки, а не установка на проектор.
