# Единый установщик — 8 октября 2026

Подготовлен автономный Windows x64 комплект Beam-Russifier-Play6 1.0.0. Python и ADB включены, исходники открыты в папке комплекта. INSTALL.cmd, CHECK.cmd и ROLLBACK.cmd запрашивают только адрес проектора. Это отдельный установщик русификации, не релиз Beam.

Проверка совместимости: точный fingerprint/product/device/API, ru-RU, серийный номер, SHA256 оригинальных NewSettings/SystemUI/Atmosphere, проверка файлов payload, диагностических свойств и текущего runtime APK в zygote. Неизвестная подмена настроек, чужая прошивка или занятая диагностика останавливают работу.

Установщик собирает backup на конкретном проекторе, затем преобразует его базы и сериализованный каталог, включает четыре RRO с пересозданием idmap, применяет скин и при необходимости mount текущего APK панели. Чужие готовые базы и пользовательский кэш не входят в payload. Временная подмена действует до перезагрузки, повторное применение выполняется тем же установщиком; автозагрузка не создаётся.

9 локальных тестов прошли: корректное и повторное преобразование обеих баз, триггеры, отказ при неизвестной иконке, точная обратимость восьми строковых handles каталога, поздний откат с сохранением новых данных, отказ при чужой прошивке/изменённом системном APK/занятом сервисе, вызов восстановления при частичной установке.

Живая проверка на XGIMI Play 6 v1.7.116: CHECK через автономный runtime; INSTALL поверх текущего перевода; ROLLBACK к состоянию до него; повторный INSTALL. Все четыре RRO STATE_ENABLED, SettingsService/MisckeyService запускаются, crash-журнал текущего процесса без FATAL EXCEPTION. Резервные копии и журналы находятся в runs, итоговая последняя установка — runs/latest-install.txt. Отмена была проверена поверх уже существующего перевода, поэтому перевод после неё сохранялся.

Первая проба нашла права 755 у root-владельца staging: adb push был отклонён до записи изменённых баз/скина/панели. Исправлено на root:shell 770 для install и restore, восстановление затем выполнено. В финальном комплекте эта проблема устранена.

На другом чистом устройстве, после перезагрузки и после полного обновления каталога проверка не выполнялась. Живой цикл использовал уже существующую подмену APK панели; ветка первого bind mount собрана из ранее проверенной команды, но в составе нового установщика с отсутствующей подменой пока отдельно не выполнялась. Имеющаяся подмена сохраняется, если её hash уже совпадает.

Распространяемый ZIP строится build_release.py по белому списку. Он не содержит runs, снимков экрана, тестовых баз или сериализованного пользовательского каталога. README описывает поддерживаемую прошивку, запуск, включённые изменения, откат и ограничения. Лицензии Python, Android platform-tools и javaobj включены.
