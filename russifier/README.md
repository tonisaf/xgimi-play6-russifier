# Русификатор XGIMI Play 6: инструкция

Комплект переводит штатные приложения XGIMI и расширяет быструю панель. Он работает отдельно от BEAM Launcher. Поддерживается **Play 6 / v1.7.116 / Android 11 / Product_dayao / dragon_healthy**, Windows 10/11 x64.

Комплект **1.19.45 / Setup1.16** для XGIMI Play 6 (прошивка v1.7.116, Android 11): 21 ресурсный оверлей, русский скин, девять временных нативных APK (настройки, SystemUI, `gmservice`, `wirelessscreen`, `atmosphere`, `upgrade`, `shutdown`, `manager`, `ota.accessories`) и helper автозапуска; модуль кнопок **0.6-test** входит в комплект и устанавливается отдельным действием. Рекомендуемый первый запуск — через EXE: подготовка создаёт базы и предлагает перезагрузку при смене языка. После загрузки перевод применяется примерно за 3 секунды (через ~21 с после включения). Полная установка после заводского сброса с другого ПК остаётся отдельным испытанием.

## Установка

В Windows-интерфейсе (`XgimiInstaller.exe`) введите IP проектора и выберите «Проверить проектор», затем «Установить русификацию» (на этой же странице можно сразу отметить часовой пояс, отключение фоновых китайских сервисов, лаунчер BEAM и модуль кнопок пульта: всё выполняется одним запуском). Если русификатор уже стоит, выберите «Обновить русификацию» (при попытке установить поверх установщик сам предложит обновление). Кнопки пульта, отдельная подготовка языка и часового пояса, лаунчер BEAM и восстановление после прерванной установки находятся в пункте «Дополнительно»; кнопки обновляются отдельно: [инструкция](REMOTE-BUTTONS.md). Краткий порядок действий — в `START-HERE.txt` рядом с EXE.

Ниже приведён ручной сценарий обычной установки без автозапуска. Для автозапуска используйте EXE или INSTALL_AUTOSTART.cmd.

1. Распакуйте весь ZIP в доступную для записи папку. Не запускайте команды внутри архива.
2. Подключите компьютер и проектор к одной сети и включите ADB на проекторе: скачайте на компьютер SystemUI Tuner, поставьте его на проектор (добавьте к имени файла `.1`, получится `…apk.1`, скопируйте на флешку; на проекторе: файловый менеджер → файл → OK → «Другие действия» → установщик APK → «Открыть один раз» → установить), включите ADB в SystemUI Tuner и узнайте IP проектора в настройках сети или в списке устройств роутера.
3. Русский язык Android включать заранее не нужно: подготовка включит его сама (после неё одна перезагрузка и повторный запуск установки). Один раз откройте штатную быструю панель и Atmosphere, чтобы приложения создали свои базы.
4. Запустите **CHECK.cmd**. Введите IP и порт ADB, например `192.168.1.100:5555`. Пустой ввод оставляет этот адрес.
5. Запустите **INSTALL.cmd** с тем же адресом и дождитесь «Готово».

Python и ADB включены в готовый ZIP. SDK, Java и администратор Windows для запуска не нужны. Установщик использует порт ADB-сервера **5038**, чтобы не мешать SDK/IDE на 5037.

CHECK проверяет файлы, прошивку, исходные APK и диагностический доступ. Он не устанавливает перевод, но использует короткую диагностическую root-команду. Отказ проверки не следует обходить отключением проверки SHA256.

INSTALL создаёт резервные копии, обновляет ресурсные пакеты, переводит собственные базы проектора, подключает русский скин и временные APK. Открытые меню могут закрыться при перезапуске приложений. Яркость, аудиовыход, геометрия и режим изображения автоматически не выбираются.

## Что меняется

- Настройки, режимы, подсказки, сведения об устройстве и сообщения.
- Экраны масштаба, поворота и ручной трапеции.
- Дата и подписи штатной быстрой панели.
- Ползунок штатной яркости источника света.
- Имена подключённых Bluetooth-устройств.
- Кнопка «Звук» с текущим выходом и переходом в штатные настройки.
- Скрытие плитки «Детский» и неработающей кнопки поиска.
- Atmosphere, меню выключения, уведомления и ряд системных утилит.

Комплект 1.16.2 также содержит перевод «Internal Battery Powered», подсказки OK и пояснения экорежима.

## Первая установка с автозапуском — экспериментальный вариант

В комплекте 1.15.0 подготовлен **INSTALL_AUTOSTART.cmd**. Он выполняет обычную установку перевода, размещает файлы boot-helper, сохраняет и дополняет OEM-политику памяти, устанавливает helper и включает только его службу специальных возможностей. На другом проекторе этот путь ещё не испытан: пока это кандидат для проверки, а не стабильная массовая поставка.

Подготовка такая же, как выше: разрешённый ADB, ru-RU после перезагрузки, созданные базы быстрой панели и Atmosphere, успешный CHECK. Первая установка требует оригинальных APK в текущей загрузке, отсутствия пакетов нашего RRO и helper. Она откажется работать поверх старого перевода. После успеха нужна полная перезагрузка для загрузки OEM-политики; установщик сам её не выполняет.

**REMOVE_AUTOSTART.cmd** отменяет эту первую установку по `runs/latest-setup.txt`. Сохраняйте весь каталог комплекта с его runs. Это возврат к состоянию перед выбранной установкой, а не заводской сброс. Для другой копии используйте:

```powershell
.\runtime\python.exe -I .\launch.py remove-autostart --device <IP:порт> --backup .\runs\<каталог>
```

При обрыве связи или отказе установки запустите **RECOVER_AUTOSTART.cmd**, укажите адрес и полный путь к каталогу runs из ошибки. Сценарий отменит незавершённую установку. Он не включает helper с неизвестным результатом и не переносит резервную копию на другой проектор. При независимых изменениях OEM-политики, helper или перевода восстановление остановится. Поколения APK сохраняются на устройстве, чтобы не удалить файлы ещё работающих процессов.

Старый исследовательский прототип без `setup.json` удаляется своей процедурой отключения ниже; REMOVE_AUTOSTART не подбирает для него вымышленную резервную копию.

## Сон, перезагрузка и тема

**Сон** сохраняет текущую сессию Android. Быстрое включение после кнопки питания не доказывает полную перезагрузку.

**Без прототипа** временные подмены APK работают до полного reboot. Повторите INSTALL тем же комплектом. Повторная установка рассчитана на уже переведённые базы и не дублирует триггеры. Сохранённой записи RRO недостаточно для гарантии всего перевода: нужны корректный idmap и скин.

**С helper** после загрузки автоматически восстанавливаются скин, нативные APK и RRO. Исследовательский прототип проверен на нашем проекторе; новая первичная установка из ZIP 1.15.0 и helper versionCode=12 пока проверены только локально.

**Смена штатной темы может убрать часть перевода без reboot.** В проверенном случае XGIMI очистил `persist.sys.xgimi.themeV2.url` и вернул штатный скин; APK и RRO остались активны. Старый helper реагирует только на загрузку. Новый helper versionCode=12 проверяет путь скина каждые 5 секунд и при сбросе запускает короткое восстановление скина. При этом приложение настроек закрывается для сброса его кэша; его можно открыть повторно. Смена темы на устройстве с новым helper ещё не проверена. Без прототипа повторное INSTALL возвращает скин. При активном прототипе не запускайте старый INSTALL поверх него без процедуры отключения ниже.

Обновление каталога Atmosphere может вернуть серверные названия. Повторное применение переводит актуальные данные; неизвестные словарю тексты остаются исходными. После обновления прошивки нужна новая проверка совместимости.

## Резервные копии и откат

Перед изменениями создаётся `runs/<дата-время-id>/before`: собственные базы и кэш проектора, прежний скин и ранее установленные RRO. `state.json` фиксирует устройство, свойства, пакеты и изменения mounts; рядом сохраняются журналы.

**ROLLBACK.cmd** отменяет последнюю успешно завершённую установку на том же проекторе. Это возврат к состоянию перед конкретным запуском: если перевод уже был установлен, он может остаться.

Поздний откат обрабатывает данные по полям, сохраняя новые записи и независимо изменённые названия. При ошибке установки предусмотрено немедленное восстановление снимков. Неизвестная замена APK, скина или RRO может остановить откат, чтобы не затереть чужие изменения.

Не удаляйте `runs`, если нужен откат, и не передавайте его другим людям: это данные конкретного проектора. ZIP не содержит runs, личных баз и журналов. Используйте ту же версию **и состав** установщика, которыми создана копия; одинаковый номер исследовательской версии не гарантирует одинаковых файлов.

Ненулевой WAL/журнал базы после остановки приложения блокирует замену. Установщик не удаляет несохранённый журнал: закройте приложения штатно и повторите проверку.

## Прототип автозапуска

Если установлен `com.beam.russifier.boot`, перед обычным INSTALL/ROLLBACK отключите исследовательский прототип. Из корня рабочего репозитория при наличии Python и локального ADB:

```powershell
python investigation/bound-startup-2026-10-08/disable_autostart.py --device 192.168.1.100:5555
```

Это **отключение автозапуска, а не удаление всего перевода**. Сценарий убирает только службу русификатора из специальных возможностей, отключает helper, отменяет job #1400 и удаляет созданную OEM-политику только при совпадении SHA256. Чужие изменения файла сохраняются. Политика перечитывается при следующем запуске Android; текущие mounts остаются до reboot или соответствующего отката.

Не удаляйте backing-файлы при активных mounts. Старый ZIP 1.13.0 не знает о последнем `systemui-native.apk`: полный возврат исследовательской конфигурации требует соответствующей процедуры, а не только старого ROLLBACK. [Подробности эксперимента](../investigation/bound-startup-2026-10-08/RESULT.md).

## Завершение первой установки

После первой установки (и после установки модуля кнопок) система XGIMI при нехватке памяти принудительно останавливает фоновые приложения, а Android при этом убирает их службы доступности из списка включённых. Защитные правила для helper и модуля (`sys_pkg_adj.json`) читаются только при загрузке, поэтому сразу после установки службы отключаются за секунды и после следующей перезагрузки не запустились бы. Команда `finish-setup` (в окне это делается автоматически в конце установки, а также пунктом «Дополнительно → Завершить настройку») перезагружает проектор, после загрузки заново включает службы helper и модуля, следит 30 секунд, что они держатся, и ждёт, пока helper применит перевод. Если проектор после перезагрузки остался выключенным, включите его с пульта: установщик ждёт до 10 минут.

```powershell
.\runtime\python.exe -I .\launch.py finish-setup --device 192.168.1.100:5555
```

## Обновление установленного helper

Если прототип уже включён на этом проекторе, распакуйте комплект 1.15.0 с каталогом `boot-helper` и запустите **UPDATE_BOOT.cmd**. Обычный INSTALL перед этим запускать не нужно. Сценарий сохраняет старое поколение, подготавливает новый комплект по SHA256, временно отключает только нашу службу, обновляет изменённые RRO и устанавливает совпадающий helper последним. Другие службы специальных возможностей сохраняются. Значения яркости, громкости и геометрии не выбираются.

При отказе установки helper изменения RRO откатываются. При потере соединения с неизвестным результатом установки служба остаётся отключённой, а журнал сохраняется. После подключения выполните:

```powershell
.\runtime\python.exe -I .\launch.py update-boot --device 192.168.1.100:5555 --recover .\runs\<каталог-обновления>
```

После успешного обновления установщик дописывает его в журнал первой установки на этом компьютере (`kit/runs/latest-setup.txt` указывает на него): удаление русификации продолжает работать с исходной резервной копией, но требует комплект той версии, которая сейчас стоит на проекторе. Если обновление выполнялось с другого компьютера, удалять надо с него же или обновлять и удалять с одного и того же.

Восстановление читает фактический APK helper и возвращает подходящее состояние. Старые каталоги поколений нельзя удалять, пока они могут использоваться процессами. UPDATE_BOOT рассчитан на обновление существующего прототипа. Для экспериментальной первой установки в 1.15.0 добавлена отдельная команда INSTALL_AUTOSTART.

## Команды

Из распакованного комплекта:

```powershell
.\runtime\python.exe -I .\launch.py check --device 192.168.1.100:5555
.\runtime\python.exe -I .\launch.py install --device 192.168.1.100:5555
.\runtime\python.exe -I .\launch.py install --device 192.168.1.100:5555 --keep-child
.\runtime\python.exe -I .\launch.py rollback --device 192.168.1.100:5555
.\runtime\python.exe -I .\launch.py rollback --device 192.168.1.100:5555 --backup <имя-каталога-в-runs>
```

`--keep-child` не добавляет скрытие плитки, но не удаляет уже установленное правило. Из исходников доступен тот же интерфейс: `python russifier/installer.py check --device <IP:порт>`.

## Диагностика

| Симптом | Что проверить |
|---|---|
| ADB недоступен | IP, сеть, включённый ADB и авторизацию |
| Прошивка / APK не совпадают | Нужна проверка новой версии; не отключать SHA256 |
| Китайский текст после смены темы | Путь русского скина: известное ограничение |
| После reboot исчезли яркость, дата, Bluetooth | Проверьте наличие прототипа и включение com.beam.russifier.boot/com.beam.russifier.boot.StartupBridge в enabled_accessibility_services. Обычный ZIP без автозапуска не делает автоприменение |
| RRO включён, но часть текста прежняя | Скин и APK в namespace самого запущенного процесса |
| Плашка переведена, пояснение экорежима нет | Для пояснения нужен новый SystemUI-патч и настоящий перезапуск persistent-процесса |
| Новая заставка на китайском | Словарь известных серверных названий |
| Откат отказывается работать | Исходный комплект и резервная копия; не перезаписывать вслепую |

Команды только для чтения из каталога комплекта:

```powershell
.\tools\adb.exe -P 5038 -s 192.168.1.100:5555 shell cat /proc/sys/kernel/random/boot_id
.\tools\adb.exe -P 5038 -s 192.168.1.100:5555 shell cat /proc/uptime
.\tools\adb.exe -P 5038 -s 192.168.1.100:5555 shell getprop persist.sys.xgimi.themeV2.url
.\tools\adb.exe -P 5038 -s 192.168.1.100:5555 shell cmd overlay list
```

Новый boot_id означает новый запуск ядра. RRO lookup не подтверждает замену литерала DEX. Снимок ADB иногда не отражает панель, которую видит пользователь; сверяйте экран и журналы.

## Доступ и ограничения

OEM debugserver этой прошивки выполняет короткие root-команды; управляющие свойства возвращаются в прежнее состояние. Занятый сервис вызывает остановку. Постоянный root-демон, Magisk и новые сетевые службы не устанавливаются. Штатный debugserver имеет побочный эффект: создание `/data/media/0/syslog` и изменение прав файлов этого каталога.

Оригинальные system/vendor APK не перезаписываются. Перевод проверен на одном проекторе; полная установка на другом ранее неизменённом экземпляре не подтверждена. Прототип испытывался полными reboot Android. Холодный старт, OTA и независимое аварийное восстановление остаются отдельными задачами. Серверные статьи помощи, текст внутри видео и неизвестные литералы не входят в полный перевод.

Версия 1.17.1 добавляет кнопки удаления сопряжения, заголовок «Режим звука», подсказку сохранения города и 37 географических названий в основных настройках и Atmosphere. Неизвестные города пока остаются на языке исходного справочника.
