# Исправления ревью — 12 октября 2026

Итоговый комплект: **руссификатор 1.19.15 / Windows Setup1.15 / кнопки пульта 0.6-test**. Исходники и APK BEAM Launcher не изменены. Загрузочные разделы, system/vendor и init-конфигурация не записывались. Изменения OEM-политики находятся только в /data.

## Что исправлено

1. **Установка/обновление кнопок и автозапуск.** remote_setup.py включён в переносимый комплект вместе с проверенным APK. В GUI доступны установка/обновление, включение, отключение и восстановление активации. install -r сохраняет назначения. Обновление сохраняет прежнее включение службы, прочие Accessibility-компоненты читаются заново и сохраняются. Новый пакет отличают от ошибки ADB: pm path отсутствующего пакета на Android 11 возвращает 1 без stderr. Неопределённый результат установки проверяется по фактическому SHA256 APK и восстанавливается по журналу.
2. **OEM-память.** Проверка после обновления выявила ещё один барьер, уже исследованный для helper: прошивка может остановить сторонний процесс и удалить его Accessibility-компонент. Установка добавляет только правило com.beam.remote: start=200/min=500/max=800. После reboot процесс действительно получил adj=500 и остался включённым. Глобальная оптимизация памяти не отключается. Перед изменением сохраняются политика, SHA256, владелец, права и контекст; замена выполняется атомарно с повторной проверкой исходного хеша.
3. **Binder и подключение.** OEM-вызовы выполняются на одном HandlerThread, главные callbacks/UI не делают transact. Добавлен таймер подключения/первой синхронизации, отдельное поколение соединения и запрет действий устаревшего listener. Переподключение ждёт очистки предыдущего поколения. Синхронный Binder невозможно принудительно отменить: зависший OEM-вызов удерживает один рабочий поток, но не UI; новые перекрывающиеся потоки/слушатели не создаются.
4. **Частичная регистрация.** KeyRegistry сохраняет подтверждённые и неопределённые регистрации. Потерянный ответ сначала разрешается снятием регистрации; отказ очистки сохраняет запись для повторной попытки. Отрицательный ответ регистрации не даёт права снимать чужую клавишу. При смерти сервера локальный учёт сбрасывается отдельно.
5. **Сборка штатного входа.** Скрипт принимает проверенный panel.apk 1.19.10 и самостоятельно декодирует его закреплённым APKTool 2.10.0. SHA256 инструмента и входа проверяются до сборки; подтверждены изменения только двух smali и одного ZIP-member. Полученный SHA256 APK **в точности совпал** с действующим патчем 98772d83d4724c3a6a9b45dcb4381e87b0a86ba6bb684d40d4117e84e2c72b25. Внешний декодированный каталог и временный путь к jar больше не используются.
6. **Упаковка и версии.** Исправлен fixture тестов упаковки. Имена APK кнопок содержат версию; существующие артефакты не перезаписываются. EXE читает версию перевода из manifest, проверяет подпись версии GUI и получает все исполняемые скрипты kit из проверенного ZIP. APK кнопок и его SHA256 включены в manifest/payload. Согласованы текущие инструкции; старые сведения модуля отмечены как архив эксперимента.
7. **Откат общей политики.** Теперь возвращается только запись своего пакета. Удаление helper не уничтожает правило независимого модуля и другие изменения. Изменённое независимо собственное правило или неизвестный формат по-прежнему останавливают откат до отключения служб.
