# Кнопки пульта: установка и обновление

Комплект 1.19.15 / Setup1.15 содержит независимый модуль `com.beam.remote` версии 0.6-test. Он проверяется на XGIMI Play 6 / v1.7.116. BEAM для него не требуется. Это экспериментальная функция: тест всех четырёх физических кнопок, медиадействий и полного reboot остаётся отдельной проверкой.

В Windows-установщике:

1. После установки русификации выберите **«Установить / обновить кнопки пульта»**. APK входит в папку kit, интернет для этого шага не требуется.
2. При первой установке модуль включает свою службу специальных возможностей. При обновлении сохраняет прежнее состояние её включения и назначения; другие службы сохраняются. Установка также добавляет точечное правило OEM-политики памяти для com.beam.remote через диагностический root-сервис. Другие правила и глобальная оптимизация памяти сохраняются.
3. Откройте штатные настройки XGIMI → Общее → **Кнопки пульта** и назначьте приложения или действия. Приложение модуля также видно в списке приложений.
4. Для ранее отключённого модуля есть отдельный пункт **«Включить настройку кнопок пульта»**. Обновление само не включает намеренно отключённую функцию.
5. **«Отключить настройку кнопок пульта»** отключает автозапуск и останавливает модуль, сохраняя назначения. Для полного удаления используйте удаление приложения `com.beam.remote`.

После установки выполните **полную перезагрузку**: OEM-политика загружается при запуске system_server. До этого прошивка ещё может остановить модуль и убрать его службу. Если это случилось до reboot, после перезагрузки используйте «Включить настройку кнопок пульта». Правило памяти само по себе не включает выключенную Accessibility-службу.

При выборе назначения экран запускает службу снова. Чтобы оставить модуль выключенным, после просмотра/изменения назначений повторите отключение. Удаление русификатора и удаление модуля кнопок — разные операции.

Последний выбор (установить, включить, выключить) запоминается в `kit/runs/remote-desired.json`: «Завершить настройку» после перезагрузки включает службу кнопок только если вы её не выключали. Если записи нет (модуль ставился старой версией), сохраняется текущее состояние службы.

Поддерживаются четыре кнопки: Youku/CIBN (2118), Tencent TV (2119), iQIYI (2120), Mango TV (2121). Действия: приложение, воспроизведение/пауза, следующий/предыдущий трек, штатное действие, отсутствие действия. Доставка медиакоманд зависит от активного плеера.

## Прерванное обновление

Журнал создаётся в `kit/runs/<операция>/remote-setup.json`; предыдущий APK сохраняется рядом как remote-before.apk, политика — в setup-before/oem-before.json. `adb install -r` сохраняет данные приложения. Установщик никогда не удаляет пакет для обхода ошибки подписи. При неподтверждённой установке возвращает только своё изменение политики; соседние правила сохраняются, независимо изменённое правило своего пакета автоматически не заменяется.

Если ПК потерял связь с проектором, выберите **«Восстановить прерванное обновление кнопок»** и каталог этого журнала. Проверяются устройство и фактически установленный APK; затем восстанавливается соответствующее состояние службы. Неизвестный APK автоматически не заменяется. Это восстановление состояния активации, а не автоматический откат данных приложения.

Проверка успеха установки включает SHA256 APK, enabled-состояние, привязку Accessibility-службы и запуск KeyService. Она не нажимает физические кнопки и не подтверждает работу конкретного плеера.

Отключение оставляет правило памяти и назначения для последующего включения. При удалении APK правило становится неактивным; оно не является установленным приложением или новым сервисом. При заводском сбросе изменения в /data удаляются. Удаление русификатора сохраняет правило независимого модуля, если тот установлен позже.

## Командная строка

Из папки kit:

```text
runtime\python.exe -I launch.py install-remote --device IP:5555
runtime\python.exe -I launch.py enable-remote --device IP:5555
runtime\python.exe -I launch.py disable-remote --device IP:5555
runtime\python.exe -I launch.py recover-remote --device IP:5555 --backup runs\КАТАЛОГ
```
