## Подтверждено локально

1. 42 теста, ошибок и пропусков нет. Включены первая установка, обратная процедура, пять границ отказа, проверка свободного места и защита от восстановления на другом устройстве.
2. Реально выполнены сформированные shell-сценарии через Git Bash: замена политики, восстановление существующего файла/удаление созданного, отказ копирования, независимая правка, несколько собственных mount-слоёв и неизвестный слой. Android-only инструменты заменены заглушками.
3. Готовый ZIP извлечён в папку с кириллицей и пробелами. Встроенный Python запускается без Python/SDK в PATH, справка семи режимов открывается. Все семь CMD отклоняют неверный адрес до ADB. Проверено поколение boot-helper, SHA256 22 payload, корректные CRLF. Выполнен только `adb version`; сервер/устройство для проверки не нужны. Отчёт: `.local/проверка поставки повтор 4/smoke.json`.
4. 159 переводов параметров сверены с сохранёнными оригиналами: несовпадений нет. CJK в проверяемых resourceChecks отсутствует. Остаточные короткие CJK-строки в DEX — кандидаты для разбора, не доказательство видимого непереведённого текста.
5. Из сохранённых исследований раннего запуска не следует готовый проверенный hook из /data. Постоянная запись APK, boot-патч, загрузка APK с изменённой подписью и автономный аварийный вход остаются неподтверждёнными. Текущая поставка системные разделы не изменяет.

## Ограничения

- Это не испытание на чистой виртуальной машине Windows: PATH ограничен на текущем компьютере.
- INSTALL_AUTOSTART требует исходного совместимого состояния, ru-RU и проверенного системного доступа; старый перевод не перезаписывается автоматически.
- REMOVE_AUTOSTART возвращает состояние перед конкретной первой установкой по её журналу. Сквозное объединение истории удаления после будущих обновлений другим комплектом не реализовано; неизвестная версия helper вызывает отказ.
- При прерывании первой установки нужен RECOVER_AUTOSTART с её журналом; автоматическое продолжение после неизвестного результата не выполняется.
- Файлы поколений оставляются после удаления, пока на них могут ссылаться процессы. Это не активный автозапуск; очистка таких файлов — отдельная процедура.
- Нужны живые испытания: первая установка, русский UI, reboot с новым boot_id, холодное включение, смена темы, удаление и повторный reboot. Реальное сохранение после этих действий локальные тесты не подтверждают.
